# Коллегия адвокатов «ПосажуZaДорого» (ПZД) — Официальный сайт

Премиальный интерактивный одностраничный сайт международной коллегии адвокатов и защитников «ПосажуZaДорого».

---

## Ключевые возможности и функционал

1. **Интро Splash-экран (Фото 1)**:
   - Крупный оригинальный логотип «ПосажуZaДорого» + рукописный слоган *«всегда рады вам помочь»* на атмосферном фоне коллегии.
   - Анимация скролла: буквы названия разъезжаются и заходят за центральную **Z**, формируя бейдж **«ПZД»** в верхнем левом углу на фоне флага текущего языка (🇷🇺, 🇺🇸, 🇨🇳, 🇧🇾).

2. **Адаптивная верхняя панель (Sticky Navbar)**:
   - Автоматически меняет цветовую палитру в зависимости от активной секции (`theme-dark`, `theme-beige`, `theme-mahogany`, `theme-gold`).
   - **Язык/Language**: Гармошка-выпадающий список с флагами стран, Windows-аббревиатурами (`RU`, `EN`, `ZH`, `BE`) и полными названиями языков.
   - **Онлайн консультация**: Зеленая мерцающая кнопка онлайна, открывающая чат-бот с автоматическим ответом *«Ищем свободного оператора...»* и индикатором набора текста.
   - **Меню (3 полоски)**: Поворот на 90° по часовой стрелке при наведении, плавное выпадающее меню с 3D-эффектом нажатия на кнопки.

3. **Секции по макетам (Фото 1, Фото 2, Фото 3)**:
   - **Главный экран (Фото 2)**: Перспективная карточка команды, этапы дела (15-минутная консультация, План действий, Уверенная защита, Решение, Переоценка рисков).
   - **История компании**: Эпичная сатирическая легенда про выживание в 90-х и экспансию в Москву, Минск, Дубай и Гонконг.
   - **Почему выбирают нас (Фото 3)**: Статистика побед, цитаты принципов, классический юридический стиль.
   - **Услуги (Физ. и Юр. лица)**: Интерактивные карточки со знаком `+`, разворачивающим юридическое определение при наведении.
   - **Методы работы и гарантии**: 4 ключевых принципа и круглосуточная готовность.
   - **Наши специалисты (Фото 3)**: Карточки адвокатов высшей квалификации с реальными рейтингами (4.70–4.95), стажем и отзывами.
   - **Форма записи на консультацию**: Форма с автосохранением черновика в Cookie, валидацией и реальным сохранением заявок.
   - **Футер**: Полупрозрачные реквизиты ИП, контакты филиалов и ироничный юридический дисклеймер.

4. **Система Cookies и реальный сбор заявок**:
   - Полноценная работа с `document.cookie`: сохранение языка (`pzd_lang`), согласия (`pzd_cookie_consent`), уникального токена сессии (`pzd_session_id`) и автосохранение черновика формы (`pzd_form_draft`).
   - **Журнал заявок в реальном времени**: Заявки мгновенно сохраняются на диск в `data/applications.txt` и `data/applications.json`, а также доступны через встроенную кнопку «📋 Журнал заявок (Real-Time)» с возможностью экспорта в 1 клик.

## Запуск проекта

### Вариант 1: Запуск встроенного сервера Node.js (Рекомендуется)
```bash
npm start
```
или
```bash
node server.js
```
Сайт откроется по адресу: **http://localhost:3000**
Файл заявок в реальном времени: `data/applications.txt` (или в браузере: `http://localhost:3000/applications.txt`).

### Вариант 2: Открытие напрямую
Вы также можете просто открыть файл `index.html` в любом современном браузере. Все локальные функции, Cookie, анимации и сохранение заявок будут работать локально в `localStorage` и через браузерный интерфейс.
