# 📖 Инструкция по запуску, тестированию и расшариванию сайта «ПосажуZaДорого»

Данный документ содержит полное пошаговое руководство:
1. Как запустить сайт на локальном компьютере для тестирования.
2. Как открыть публичный доступ для друзей через сервис туннелирования **Tunyl.com**.
3. Как в реальном времени просматривать и скачивать поступающие заявки клиентов на консультацию.

---

## 🚀 Шаг 1: Запуск сайта на компьютере

1. Откройте терминал (PowerShell или Командную строку) в папке с проектом:
   ```bash
   cd "C:\Users\Никита\OneDrive\Рабочий стол\Макеты\Пробник V2"
   ```
2. Запустите сервер командой:
   ```bash
   node server.js
   ```
   *(или `npm start`)*
3. Сайт откроется локально по адресу:
   👉 **http://localhost:3000**

> [!NOTE]
> Не закрывайте это окно терминала, пока тестируете сайт — в нем работает сервер.

---

## 🌐 Шаг 2: Как дать друзьям доступ через сервис Tunyl.com

Чтобы друзья или клиенты могли зайти на ваш сайт со своего телефона или компьютера из любой точки мира через интернет, используйте сервис **Tunyl**.

### Команда для запуска туннеля:
Откройте **второе (отдельное)** окно терминала в папке проекта и выполните команду:

<pre>
npx start-tunyl@latest --token <span style="background-color: #fef08a; color: #854d0e; padding: 3px 8px; border-radius: 4px; font-weight: bold; border: 1px solid #eab308;">O70eWKCNKamY1fNlLNNoHuauGd8KeTNhAI2TsqimKvDoLuO3wrFTQ6l1fnSz</span> --port 3000
</pre>

```bash
# Текстовый вид команды для копирования:
npx start-tunyl@latest --token O70eWKCNKamY1fNlLNNoHuauGd8KeTNhAI2TsqimKvDoLuO3wrFTQ6l1fnSz --port 3000
```

### 💡 Как заменить токен, если он изменится:
В команде выше часть между `--token` и `--port 3000` — это ваш персональный ключ.

- Шаблон команды:
  `npx start-tunyl@latest --token [ВСТАВЬТЕ_ВАШ_НОВЫЙ_ТОКЕН_СЮДА] --port 3000`

### Что произойдет после запуска команды:
1. Сервис Tunyl подключится к вашему локальному серверу (порт 3000).
2. В терминале появится готовая публичная ссылка (например: `https://xxxxxx.tunyl.com`).
3. Скопируйте эту ссылку и отправьте друзьям в Telegram / WhatsApp — они смогут полноценно тестировать сайт, менять языки, отправлять сообщения в чат и оставлять заявки.

## 📋 Шаг 3: Как смотреть заявки клиентов на консультацию

Все заявки, которые пользователи отправляют через форму на сайте, мгновенно сохраняются и доступны для чтения в реальном времени тремя способами:

### Способ 1: Прямо в файле на диске (Рекомендуется)
Откройте текстовый файл журнала в папке проекта:
📁 **`C:\Users\Никита\OneDrive\Рабочий стол\Макеты\Пробник V2\data\applications.txt`**

В нем каждая заявка записана в удобном читаемом формате:
```
[#LEAD-0001] 24.08.2026, 13:10:00 (МСК)
Имя:       Константин Власов
Телефон:   +7 (999) 777-88-99
Email:     vlasov@holding.ru
Город:     Москва (ЦАО)
Категория: Защита бизнеса и активов
Суть дела: Рейдерская атака на складской комплекс в Подмосковье. Требуется срочный выезд адвоката.
----------------------------------------------------
```
*Также доступен файл в формате JSON:* **`data/applications.json`**.

### Способ 2: В браузере по прямой ссылке
Вы можете открыть журнал заявок прямо в браузере (даже при удаленном тестировании через туннель):
👉 **http://localhost:3000/applications.txt** *(или `https://ваш-туннель.tunyl.com/applications.txt`)*
